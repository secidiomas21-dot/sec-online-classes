SEC ONLINE CLASSES - GITHUB PAGES

COURSE STRUCTURE
- Basic 1: Unit
- Basic 2: Unit + Conversation
- Intermediate: Unit + Conversation + Listening
- Advanced: Unit + Conversation + Listening

CONTENTS
- index.html: student library
- teacher.html: teacher guides (not linked from the student library)
- materials/: PDFs and MP3s
- reports/: inventory, checksums and missing-file report

UPLOAD WITH GITHUB DESKTOP
1. Create a new empty GitHub repository.
2. Open GitHub Desktop and clone the repository.
3. Copy the CONTENTS of this folder into the cloned repository.
4. Commit and push.
5. GitHub: Settings > Pages > Deploy from a branch > main / root.
